# Security Policy

## Supported Versions

Only the latest release of **Lummo Studio** receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 2.x.x   | :white_check_mark: |
| < 2.0.0 | :x:                |

## Reporting a Vulnerability

We take the security of Lummo Studio seriously. If you discover a security vulnerability, please do **NOT** open a public issue.

Instead, please report vulnerabilities privately:

1. **Email or Private Message**: Contact the repository maintainers directly or use GitHub's Private Vulnerability Reporting feature.
2. **Details to Include**:
   - Description of the issue and potential impact.
   - Steps to reproduce or proof-of-concept code.
   - Any suggested mitigations.

### Response Timeline
- We will acknowledge receipt of your vulnerability report within **48 hours**.
- We aim to provide a status update or security fix release as quickly as possible depending on severity.

Thank you for helping keep Lummo Studio safe! 🛡️
